### 2.1 页面声明的图册清单 vs. 实际实现

## 3. 数据与渲染链路

1. **时间轴**：`timeline(sheet)` 为每张图构造映射（`hzview.js:18–31`）。S-000 覆盖 0 到 `Tmax`，提升段放慢 4×（`:25`）；S-301 覆盖 `K.lift1.start` 到 `K.head.end`，按白天/夜间加权（`:22–24`）。
2. **姿态与构件**：`HZ.pose(t)`、`HZ.jackRead(t)` 等由 `hzseq.js` 提供；`setT(t)` 统一驱动 3D、HUD 与图纸（`hzview.js:533–545`）。
3. **3D**：构件合并为一个网格（`compile()`，`:135–158`），墨线与实景两套材质（`patchStd` `:99–106`，墨线 `:109–115`，线段 `:117–127`）。地面与城市背景（`:170–210`）。塔吊、履带吊、运输车、转轴、油缸、工人每次时间变化重建（`rebuildDyn`，`:252–312`）。
4. **审计**：`auditWorker()`（`hzview.js:582–588`）在 Worker 中执行 `HZ.audit()`，结果写入说明面板（`fillInfo`，`:568–580`）。审计未完成时用 `HZ.audit()` 同步兜底（`:588`）。
5. **HUD**：`hud()`（`:500–510`），S-301 的大号读数由 `big301()`（`:485–492`）给出，S-000 由 `hudBig()`（`:493–499`）给出。
6. **图纸调度**：`SHEETS` 数组（`:591`）只含 `sh-jack`；每帧至多画一张（`:671–672`）。

## 5. 风险与待办

按影响排序：

1. **图册编号与实现严重不符（高）**。六张图中只有两张可用，且 URL 对未实现编号静默回落到 S-000（`hzview.js:10`）。若文档或外部链接指向 S-101 等编号，用户看到的是总图而非报错。
2. **三张 A 系列图纸是死代码（高）**。`hzsheet.js:57`、`:109`、`:153` 的 `section`、`plan`、`lift` 从未被调用，也没有对应画布。其中 `lift` 带有吊点凸包校核（`:175–183`），是否要接回需要产品决策。
3. **页面文案与实现不一致（中）**。`hzwest.html:157`、`hzview.js:3`、`hzsheet.js:3` 都称“三张图纸”，实际只有一张。
4. **外部依赖（中）**。Three.js 从 `unpkg.com` 加载（`hzview.js:6`、`:36`），离线只能用 `?three=local`（`hzview.js:35`）。
5. **代码可读性（低–中）**：
   - `hzview.js:334` 同一行有三段尾注释，其中两段是重复的“3 = 东偏南”说明，且 `CAM.fin` 在 `:340` 的调用已被注释掉，仅剩 `:320` 定义。
   - `hzview.js:413` 的判断条件 `(prev == null || prev > 0 || n === 0 || true)` 恒为真，`prev` 变量实际无效。
   - 大量超长行（单行 200+ 字符）增加审阅难度。
6. **版本标记不统一（低）**：`hzwest.html:7` 标题写 `hzwest-set2a`，`hzview.js:2` 写 `hzwest-r2`，`hzview.js:17`、`hzsheet.js` 注释混用 set1/set2a/set2b/set2c。
7. **未运行验证**：本轮只做静态阅读，没有在浏览器中打开页面，也没有运行 `tests/test_*.py` 或 `tests/test_*.js`。上述结论全部来自源码。
